# Solution Vision: sanark

> Plataforma web profesional para Sanark Studio — servicios de Lectura Estructural

## Identity

### Description

Sanark es la plataforma digital de Sanark Studio (sanark.studio), un servicio profesional de **Lectura Estructural** — sesiones de coaching/consultoría arquitectónica de 90 minutos (180€). La aplicación permite a los usuarios conocer el servicio, entender el proceso, y reservar sesiones a través de un formulario integrado con confirmación por email y enlace de pago. Construido con React + Vite + Supabase, el sitio combina una experiencia visual inmersiva (parallax, partículas, animaciones) con un flujo de conversión claro hacia la reserva.

## Outcomes

| **Outcome** | **Description** |
|-------------|-----------------|
| **Conversión de Reservas** | Los visitantes pueden reservar una sesión de Lectura Estructural de forma autónoma, recibiendo confirmación inmediata por email con enlace de pago |
| **Presencia Digital Profesional** | Sanark Studio proyecta credibilidad y profesionalismo a través de un sitio moderno con experiencia visual cuidada |
| **Educación del Servicio** | Los visitantes comprenden qué es la Lectura Estructural, el proceso Sanark y las diferencias entre modalidades (introductoria vs. estructural) |
| **Operación Automatizada** | El administrador (sanark.studio@gmail.com) recibe notificaciones automáticas de cada reserva sin intervención manual |
